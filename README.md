# AI-assisted phyphox modules

Custom experiments for the free [phyphox](https://phyphox.org) app, built with AI assistance.


## Install all modules at once
1. Open phyphox, tap **+** and choose the QR code option.
2. Scan the code below (the phone needs internet).
3. Tap **save all to collection**.

Direct download: [modules.zip](https://raw.githubusercontent.com/praveen2600/phyphox-modules/main/modules.zip)

## Modules
| Module | What it does |
|---|---|
| Motion lab | Removes the sensor offset, then integrates acceleration to velocity and displacement (or angular velocity to angle) |
| Earth's magnetic field | Horizontal and vertical field and dip angle from a hand-held rotation, with tilt correction |
| GPS lab | Distance, displacement, speed from a fitted slope, and a North-up track map for any section of a walk |
| Heartbeat | Finds each heartbeat on the chest (seismocardiogram) and overlays the beats |
| Basic statistics | Mean, standard deviation and histogram for any interval and sensor |
| Tremor | Power spectrum and peak frequency of hand tremor |
| PPG | Pulse wave from the camera with a fingertip on the lens |
| Pressure difference | Height difference from two averaged pressure ranges |
| Measure and fit | Power-law fits for the fall-off of light or a magnet's field with distance |
| Plot and fit | Straight-line, power-law and log–log fits for typed data |

## Notes
- Requires phyphox 1.2.1 or newer.
- The light sensor works on Android only.
- The heartbeat and PPG modules are for teaching, not medical use.
