# AI-assisted phyphox experiments

Custom experiments for the free [phyphox](https://phyphox.org) app, built with AI assistance.


## Install all experiments at once
1. Open phyphox, tap **+** and choose the QR code option.
2. Scan the code below (the phone needs internet).
3. Tap **save all to collection**.

<img width="540" height="540" alt="qr-all-modules" src="https://github.com/user-attachments/assets/0c6b9012-920e-4e00-87f8-5acbef541292" />



Direct download: [modules.zip](https://raw.githubusercontent.com/praveen2600/phyphox-modules/main/modules.zip)

If you installed an earlier version, delete the old copies in phyphox first. phyphox adds a second copy instead of replacing an experiment with the same name.

## Experiments
| Experiment | What it does |
|---|---|
| Motion Lab | Removes the sensor offset, then integrates acceleration to velocity and displacement (or angular velocity to angle) |
| Motion Lab Challenge | Asks six questions about your own motion; you answer on the graph and phyphox checks the answer |
| Earth's Magnetic Field Lab | Horizontal and vertical field and dip angle from turning on the spot with the phone held flat, with tilt correction |
| GPS Lab | Distance, displacement, speed from a fitted slope, and a North-up track map for any section of a walk |
| Heartbeat Lab | Finds each heartbeat on the chest (seismocardiogram) and overlays the beats |
| Malus's Law Lab | Tests Malus's law with the camera and the gyroscope, with the phone turning on a laptop screen |
| Malus's Law Challenge | The student chooses the law and the bright position, and answers questions checked against the experiment's own fit |
| Basic Statistics | Mean, standard deviation and histogram for any interval and sensor |
| Tremor Lab | Power spectrum and peak frequency of hand tremor |
| PPG Lab | Pulse wave from the camera with a fingertip on the lens |
| Pressure Lab | Height difference from two averaged pressure ranges |
| Measure and Fit Lab | Power-law fits for the fall-off of light or a magnet's field with distance |
| Plotting Lab | Straight-line, power-law and log–log fits for typed data |

## Notes
- Requires phyphox 1.2.1 or newer.
- The light sensor works on Android only.
- Heartbeat Lab and PPG Lab are for teaching, not medical use.
